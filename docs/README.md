# Документация по Table Tennis Ultimate

Пять файлов. Все — про дизайн-программу; ни один не участвует в сборке (`build.py` читает только `.part` и `.css`), поэтому их можно перемещать и переименовывать без риска для `index.html`.

## Что здесь
| Файл | Отвечает на вопрос | Объём |
|---|---|---|
| `BRIEF-ASSETS.md` | **Сколько всего графики и как раздать по партиям.** 14 партий Б1–Б14, манифест поставки, волны, блокировки | 486 единиц |
| `BRIEF-GRAPHICS.md` | **Как это выглядит.** Инвентарь сборки, стиль, реестр имён иконок A–N, размеры, форматы, вес | 288 иконок + 128 ассетов + 16 FX |
| `BRIEF-PACKAGES.md` | **Зачем и куда встаёт.** 14 самостоятельных пакетов П1–П14, носитель → уровень детализации, правила формулировок, 4 проверки | 14 пакетов |
| `BRIEF-EGGS.md` | **Что зацепит своих.** 30 пасхалок для полупро, пародийные бренды, мерч-бренд, протокол именования | 30 + 6 резерва |
| `BRIEF-CAREER.md` | **Как держит режим карьеры.** Три рычага (деньги / расстояние / репутация), страна и сила, спонсоры, форс-мажоры, мерч-трение, микроразвилки, экраны | 16 разделов |

## Порядок чтения
1. `BRIEF-PACKAGES.md` — модель и решения (почему уровень задаёт носитель, почему нет маскотов).
2. `BRIEF-GRAPHICS.md` — реестр имён и техтребования.
3. `BRIEF-ASSETS.md` — производственные партии, если отдавать работу разным исполнителям.
4. `BRIEF-CAREER.md` и `BRIEF-EGGS.md` — содержательная часть, на которую графика ссылается.

## Сквозные правила (действуют во всех файлах)
- **Изображений людей нет.** Соперник = ник-плитка, строка в сетке, текстовая карточка и его ракетка на поле.
- **Аудитория международная.** Никаких локальных реалий одной страны; термины из глоссария ITTF; строки UI короткие; слоганы перезаписываются, а не переводятся.
- **Юмор бьёт вверх.** Смешны бренд, регламент и бюрократия; местная культура всегда права. Религия, еда как национальная черта, акценты, карикатуры — под запретом.
- **Кожи на поле — задача к моменту подключения геймплея**, а не дефект.
- **Один стиль на весь корпус:** сетка 24, оптика 1.8, `currentColor`, свечение только под смыслом.

## Открытые вопросы (все ждут решения, ни одно не блокирует файлы)
1. Чинить ли баг `js6.part:507` — бесплатная полка сезонного пропуска никогда не выдаёт gems (условие `'20 ◈' === ''` всегда ложно).
2. M1 карьеры: 28 городов / 60 событий или начать с 12 / 18.
3. Эталонные 6 ассетов для всего корпуса (икона, рендер ракетки, сцена арены, key art, артефакт, ник-плитка).
4. Онбординг: технические разрезы кисти и стойки остаются или только траектории мяча.
5. Партию Б9 (20 системных иконок) отдавать отдельным подрядчикам без авторства или держать внутри команды.
